CONTRACT · v1 · ISSUE #43 · PBI T-7

Mitchell-style decomposition

Optional workflow for oversize agent diffs. Primary home: axel. Light hooks: avril. Default: off.

Reference: #43 · Mitchell Hashimoto pattern (draw the owl → threshold → decompose).

1. Purpose

Any agent-generated diff that is hard to review signals the problem must be decomposed. This contract turns that human workflow into explicit AVRIL/AXEL rules without replacing stacked PRs, PETC, intake gates, or code GAN BLESS.

2. Activation (opt-in only)

  • Default off. Mode-off AXEL/AVRIL behavior is unchanged — no new mandatory steps.
  • On when: human says “mitchell”, “decomposition mode”, “draw the owl”, or harness discloses decomposition_mode: true (or equivalent).
  • Threshold override: harness disclosure decomposition_loc_threshold (number). Default 1500.

3. LOC measurement

  • LOC = sum of added + deleted lines from git diff --numstat on the phase (or uncommitted) diff unless the harness discloses another scope.
  • Ignore pure renames/binary noise when numstat reports “-” where practical; when uncertain, count conservatively (treat as over threshold if ambiguous and large).
  • Compare to threshold T (default 1500). Over threshold ⇒ decomposition path; at or under ⇒ normal commit path (still GAN + AC).
git diff --numstat
# LOC = sum(col1) + sum(col2) over rows with numeric cols

4. Phases

  1. Draw the owl (bounded spike) — Loose implement/explore to discover seams. Label spike. Time-box. Output is learning + candidate task list, not merge authorization.
  2. Threshold check — Measure LOC. If ≤ T and reviewable (<10 min deep review target), continue normal AXEL GAN → commit.
  3. Decompose — If > T (or unreviewable), do not commit. Break into atomic incremental tasks.
  4. Massage — Rewrite tasks away from “the shape we just hacked” into general, maintainable vertical slices with clear AC.
  5. Execute chunks — Each chunk through PETC + code GAN; recurse threshold on each chunk. Parallel Task subagents optional; sequential fallback required.
  6. Periodic re-owl — Optional bounded re-attempt of the whole feature; still subject to threshold, intake, GAN, AC. Never a shortcut around AVRIL blessing.

6. HITL

Human-in-the-loop remains required for UI, public APIs, and architectural invariants. Decomposition mode does not auto-merge or skip human gates the harness already requires.

7. Non-goals

  • Third orchestration skill in v1
  • Default-on behavior
  • Owl as silent execution authorization
  • Mandatory multi-agent parallelism
  • Replacing PETC, stacked PRs, or code GAN
  • CI LOC enforcer binary (process/skill only unless a later PBI adds tooling)
