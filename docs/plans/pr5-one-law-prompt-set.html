03

Decisions settled before dispatch

  • OCaml is in. Reverses the “park OCaml” recommendation. ocaml-code-writer (19,551 B) is absorbed in 5b. Second consequence: OCaml gains adversaries for the first time — §2.4’s ocaml reviewer ✗ tester ✗ architect ✗ row closes the moment the gate cards go language-neutral in 5c.
  • The graph carries no language. code-gan.json’s generate node retargets to code-writer, not to a book. The book is disclosed per project and the graph declares requires.book: true, so “runs without a disclosed book” becomes a mechanical failure. Retargeting to rust would force code-gan-<lang>.json forks with identical topology — the duplication PR 3 deleted rust-team-lead to kill.
  • The Rules projection is <book>/RULES.md. One generated file per book: committed (bootstrap copies trees and never runs generators), drift-gated, ids fully qualified. Not under references/ — that directory is the extractor’s input, and keeping it How-only makes “the reviewer never sees How” checkable.
  • The contract is universal; the topic set is per book. Every reference carries ## Rules + ## How; ids are append-only; RULES.md is generated. Which topics a book has is the book’s business — JS has no .mli, Elm has no unsafe. The extractor never hardcodes a topic list.
  • Staged duplication is allowed and time-boxed. 5a and 5b create books while the three writers still exist. During that window the old path stays authoritative — harness-parameters.md still discloses the Rust triple — so the books are inert staging, not a second live law. Superseded skills are frozen and carry a deprecation marker with their measured bytes as a drift detector.
